# Personal Lock Screen

[RU](README_RU.md) | [EN](README.md)

Полноэкранное приложение для добровольного самоограничения на собственном компьютере Windows с одноразовыми кодами через Telegram и Cloudflare Workers.

## Кратко

При запуске приложение показывает новый шестизначный `PC_ID`. Отправьте боту:

```text
/start 482913
```

Вместо `482913` используйте ID из окна. Бот отправит OTP-код.

Установщик позволяет выбрать русский или английский язык. Выбранный язык используется интерфейсом и Telegram-ботом.

## Важно

Это инструмент самоограничения, а не граница безопасности. Task Manager, права администратора, безопасный режим и внешние средства восстановления не блокируются.

Не публикуйте Telegram-токен, пароли, chat ID, Worker URL и KV ID.
