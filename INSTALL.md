# Инструкция по установке Personal Lock Screen

## Перед установкой

Установщик предназначен для личного компьютера владельца. Он меняет оболочку Windows для текущего пользователя и запускает экран блокировки при входе в систему.

Перед установкой убедитесь, что у вас есть доступ к своему Telegram-боту.

## Установка

1. Запустите `PersonalLockScreenSetup.exe`.
2. Выберите язык: `Русский` или `English`.
3. На шаге установки задайте резервный пароль.
4. Введите пароль повторно для проверки.
5. Подтвердите предупреждение о включении режима Winlogon Shell.
6. Дождитесь завершения установки.
7. Перезагрузите компьютер.

Резервный пароль нужен для разблокировки, если Telegram временно недоступен.

## Разблокировка через Telegram

После входа в Windows появится экран блокировки. В нижней части окна будет показан новый шестизначный `PC_ID`, например:

```text
482913
```

Отправьте своему Telegram-боту:

```text
/start 482913
```

Вместо `482913` используйте ID, который показан на экране.

Бот отправит одноразовый код. Введите этот код в окно блокировки и нажмите «Подтвердить».

`PC_ID` создаётся заново при каждом запуске, поэтому при следующем входе нужно отправить боту новый ID.

## Резервная разблокировка

Введите пароль, который был задан во время установки, и нажмите «Подтвердить».

## Индикатор языка

В правом нижнем углу отображается текущая раскладка клавиатуры, например `RU` или `EN`.

Переключить язык можно стандартными сочетаниями Windows:

- `Win + Space`;
- `Alt + Shift`.

## Удаление программы

Удаление рекомендуется выполнять после разблокировки Windows:

1. Откройте «Параметры Windows» → «Приложения».
2. Найдите `Personal Lock Screen`.
3. Нажмите «Удалить».
4. Перезагрузите компьютер.

При удалении программа восстановит прежнюю оболочку Windows.

## Если после входа не появился рабочий стол

1. Нажмите `Ctrl + Shift + Esc`.
2. Откройте «Запустить новую задачу».
3. Введите:

```text
explorer.exe
```

4. После появления рабочего стола запустите удаление `Personal Lock Screen`.

Если приложение было установлено из исходников, для отката можно выполнить:

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall_winlogon.ps1
```

После удаления или отката перезагрузите компьютер.

## Важная информация

- Не удаляйте программу вручную из папки установки до отключения Winlogon Shell.
- Не публикуйте Telegram-токен, резервный пароль, Worker URL и личные идентификаторы.
- Это приложение блокирует интерфейс на уровне текущего пользователя, но не заменяет стандартный экран входа Windows.
